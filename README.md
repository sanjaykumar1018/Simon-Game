# Simon Game

A modern, professional web-based implementation of the classic Simon memory game. Test your memory by repeating the sequence of lights and sounds that gets progressively longer with each round.

## 🎮 Features

*   **Professional UI**: sleek dark theme with a radial gradient background and neumorphic button design.
*   **Responsive Design**: Fully optimized for desktop and mobile devices.
*   **Enhanced Animations**: Smooth transitions, glow effects, and button press animations for a realistic feel.
*   **Sound Effects**: Distinct sounds for each color and a buzzer for wrong answers.
*   **Interactive Gameplay**:
    *   **Start Button**: Clear entry point for both mouse and touch users.
    *   **Keyboard Support**: Press any key to start (desktop).
    *   **Visual Feedback**: Buttons light up and shrink slightly when pressed.

## 🕹️ How to Play

1.  Open `index.html` in your web browser.
2.  Click the **Start Game** button (or press any key on your keyboard).
3.  The game will flash a color and play a sound.
4.  Click the button that just flashed.
5.  If you are correct, the game will add another color to the sequence.
6.  Repeat the entire sequence from the beginning.
7.  The game continues until you press the wrong button.
8.  **Game Over**: The background will flash red, and you can restart to try again!

## 🛠️ Technologies Used

*   **HTML5**: Structure and semantic markup.
*   **CSS3**: Custom styling, Flexbox for layout, and CSS animations.
*   **JavaScript (jQuery)**: Game logic, DOM manipulation, and event handling.
*   **Google Fonts**: "Press Start 2P" font for that retro arcade look.

## 🚀 Setup

No installation required!

1.  Clone or download this repository.
2.  Locate the `index.html` file.
3.  Double-click it to open it in your default web browser.
